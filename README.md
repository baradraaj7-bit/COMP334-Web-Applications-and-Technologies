# COMP 334 – Web Applications and Technologies

This repository contains my coursework for the **Web Applications and Technologies (COMP 334)** course at **Birzeit University**.

## 📚 Course Assignments

### Assignment 1 – HTML
- Created static HTML pages for a Maintenance Request Ticketing System.
- Practiced HTML forms, tables, links, images, and semantic elements.

### Assignment 2 – PHP & MySQL
- Developed a dynamic Maintenance Request Ticketing System.
- Implemented user login and role-based dashboards for managers and customers.
- Added ticket searching, viewing, assignment, and maintenance request submission.
- Used PHP, MySQL, and PDO for database operations.

### Assignment 3 – CSS
- Improved the design and layout of the ticketing system using CSS.
- Styled forms, tables, navigation, dashboards, and ticket details pages.
- Added hover and focus effects and responsive layouts.
